1. ¿Un sistema operativo es?
A. Un tipo de software que traduce código fuente.
B. Un programa que gestiona los recursos del ordenador.
C. Un dispositivo de almacenamiento externo.
D. Un lenguaje de programación.
ANSWER: B

2. ¿Qué significa CPU?
A. Central Process Unit
B. Central Processing Unit
C. Computer Personal Unit
D. Control Program Utility
ANSWER: B

3. ¿Una base de datos es?
A. Un conjunto de programas de edición de texto.
B. Un archivo con imágenes.
C. Un sistema para almacenar y organizar información.
D. Un lenguaje de programación.
ANSWER: C

4. ¿Qué tipo de memoria es volátil?
A. ROM
B. Disco duro
C. RAM
D. SSD
ANSWER: C

5. ¿Cuál de los siguientes es un lenguaje de programación?
A. HTML
B. CSS
C. Python
D. HTTP
ANSWER: C

6. ¿Qué dispositivo se utiliza para la entrada de datos?
A. Monitor
B. Teclado
C. Impresora
D. Altavoz
ANSWER: B

7. ¿Qué significa “bit”?
A. Binary Number
B. Binary Digit
C. Binary Code
D. Basic Integer Type
ANSWER: B

8. ¿Cuál es la unidad principal de almacenamiento en un ordenador?
A. CPU
B. Monitor
C. Disco duro
D. Router
ANSWER: C

9. ¿Qué hace un compilador?
A. Ejecuta directamente el código fuente.
B. Traduce el código fuente a lenguaje máquina.
C. Edita imágenes.
D. Gestiona archivos del sistema operativo.
ANSWER: B

10. ¿Qué tipo de software es Microsoft Word?
A. Sistema operativo
B. Aplicación de procesamiento de texto
C. Lenguaje de programación
D. Antivirus
ANSWER: B
